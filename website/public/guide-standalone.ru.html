02

Первый запуск

Шаг 1 — Создание PIN

При первом включении устройство предлагает создать PIN-код. Этот PIN шифрует главный ключ устройства — он требуется при каждом запуске.

Шаг 2 — Подключение к WiFi

После создания PIN устройство запускает точку доступа. Подключитесь к ней с телефона или компьютера. Автоматически откроется captive portal — выберите сеть WiFi и введите пароль. После сохранения устройство перезагрузится.

Примечание WiFi можно также настроить позже через веб-кабинет в режиме AP, до запуска автоматической настройки.

Шаг 3 — Веб-кабинет запускается автоматически

При первой загрузке после настройки WiFi веб-сервер запускается автоматически. Введите IP-адрес устройства или mDNS-адрес в браузере для завершения регистрации.

03

Режимы работы

После ввода PIN при каждой загрузке устройство показывает экран выбора режима. На экране отображаются две кнопки — они соответствуют двум не-дефолтным сетевым режимам. Третий режим (заданный по умолчанию) запускается автоматически через 2 секунды, если ни одна кнопка не нажата.

Режим по умолчанию настраивается в Настройки → Режим загрузки. Заводской режим — WiFi Client. Каждое нажатие кнопки сбрасывает таймер на 2 секунды.

05

HID передача паролей

Устройство действует как аппаратная клавиатура и напрямую вводит выбранный пароль — приложения на принимающем устройстве не требуются.

T-Display ESP32 (классический): только BLE HID.
T-Display-S3: BLE HID или USB HID. При удержании обеих кнопок на экране появляется промпт выбора режима. Устройство предвыбирает настроенный режим по умолчанию — дождитесь таймера авто-выбора или нажмите кнопку для переключения перед началом передачи. USB HID не требует сопряжения или драйверов.

РежимHID доступен
Офлайн✓ Да
AP✓ Да
WiFi — веб-сервер ВЫКЛ✓ Да
WiFi — веб-сервер ВКЛ✗ Нет
T-Display-S3 — USB HID USB HID доступен в тех же условиях, что и BLE HID. Промпт выбора режима (BLE или USB) появляется после удержания обеих кнопок. Режим по умолчанию настраивается в Настройки → Режим HID.

Первое подключение (сопряжение)

  1. На экране менеджера паролей удержите обе кнопки
  2. На дисплее устройства появится PIN-код
  3. На телефоне выберите устройство в настройках Bluetooth и введите этот PIN
  4. Сопряжение сохранено — в следующий раз PIN не нужен

Отправка пароля

  1. Выберите нужный пароль кнопками ▲ / ▼
  2. Пароль передаётся на телефон как ввод с клавиатуры
  3. Нажмите ▲ Верх для выхода из BLE и возврата к паролям
Примечание Если настроен аппаратный BLE PIN, устройство запросит подтверждение на экране перед передачей.
06

Сброс до заводских настроек

  1. Нажмите RST
  2. Сразу после перезагрузки — удержите обе кнопки одновременно
Внимание Сброс навсегда удаляет все TOTP/HOTP-ключи, пароли, данные WiFi, сессии и PIN. Экспортируйте данные перед сбросом, если нужно их восстановить.
07

Веб-кабинет — Доступ и вход

Как открыть

Введите IP-адрес устройства в браузере или используйте mDNS-адрес: http://t-disp-totp.local (имя хоста настраивается в Настройках).

В режиме AP captive portal открывается автоматически при подключении к WiFi-сети устройства.

Регистрация

При первом входе устройство перенаправляет на страницу регистрации. Создайте имя пользователя и пароль, затем войдите с теми же данными.

Известная ошибка Страница регистрации или входа может отображаться пустой при первой загрузке. Обновите страницу — она отобразится корректно.
Попытки входа Несколько неудачных попыток входа заблокируют доступ до перезагрузки устройства.
07b

Виджет-бар

Виджет-бар — тонкая полоска в верхней части интерфейса веб-кабинета. Содержит два элемента по разным сторонам.

ЭлементРасположениеОписание
🔋 БатареяЛевая сторонаПоказывает текущий уровень заряда аккумулятора (устройство должно иметь подключённый LiPo-аккумулятор 3.7В). Отображает процент и напряжение. При зарядке показывается анимированная иконка.
🌐 ЯзыкПравая сторонаИконка флага с выпадающим меню — переключение языка интерфейса веб-кабинета. Доступные языки: английский, русский, немецкий, китайский, испанский. Выбор сохраняется в браузере и сохраняется между сессиями.
Переключатель языка Смена языка мгновенно обновляет все надписи, кнопки и уведомления — перезагрузка страницы не требуется. Настройка хранится в браузере, не на устройстве.

Ключи — TOTP & HOTP

Добавление ключа

Введите имя и секретный ключ. Настройки по умолчанию: TOTP, SHA1, 6 цифр, интервал 30 секунд.

Нажмите Дополнительные настройки для изменения:

ТипTOTP, HOTP

Ключ также можно добавить, загрузив скриншот его QR-кода.

Действия с ключами

Экспорт и импорт

  1. Нажмите Активировать экспорт и введите пароль веб-кабинета
  2. Выберите ключи для экспорта и нажмите Экспорт — скачается файл .enc
  3. Для импорта: активируйте экспорт снова, нажмите Импорт, загрузите файл .enc

Файл .enc также можно открыть в decrypt_export.html (корень проекта) — офлайн-редактор для просмотра, расшифровки и редактирования ключей на компьютере.

ЭлементФункция

Категории паролей

Каждому паролю можно присвоить категорию для организации хранилища. Значок категории отображается над именем пароля в списке.

КатегорияНазначение
📋 НетБез категории (по умолчанию)
🌐 ВебЛогины на веб-сайтах
📱 ПриложениеМобильные и десктопные приложения
🖥 ЛокальныйУчётные данные локальных систем и устройств
🔑 Ключ / ТокенAPI-ключи, токены, секреты

Способы назначения категории:

  • Быстрое изменение: нажмите на значок категории прямо в строке пароля — появится небольшое меню выбора, после выбора категория сохраняется немедленно.
  • Форма редактирования: откройте Edit для любого пароля — выбор категории находится над индикатором сложности. Измените и нажмите Save.
  • Форма добавления: выберите категорию до нажатия Add Password.

Панель фильтрации над таблицей паролей позволяет отображать только записи выбранной категории. Нажмите 📋 Все для отображения всех паролей.

Авто-отправка (Enter)

При включении устройство автоматически нажимает Enter после ввода пароля через BLE или USB HID клавиатуру. Полезно для форм входа, где поле пароля является последним. Включайте только если целевое приложение ожидает Enter для подтверждения — в других случаях это может вызвать нежелательные действия.

На экране устройства отображается бейдж ENT для паролей с включённой авто-отправкой.

Отправка логина перед паролем

Когда включено, устройство сначала вводит логин, затем нажимает Tab или Enter (настраивается), ждёт небольшую задержку и затем вводит пароль. Полезно для форм входа, требующих автоматического заполнения обоих полей.

ОпцияОписание
ЛогинИмя пользователя или email, которые нужно ввести перед паролем
Режим навигацииEnter — нажать Enter после ввода логина (переход к следующему экрану или отправка). Tab — нажать Tab после ввода логина (переход к следующему полю, например полю пароля на той же странице).
Задержка перед паролем (мс)Время ожидания в миллисекундах после нажатия Tab/Enter перед вводом пароля. По умолчанию: 300 мс. Актуально только в режиме Enter. Увеличьте, если целевому сайту нужно больше времени на загрузку следующей страницы.

Бейдж LOGIN ⏎ (режим Enter) или LOGIN ⇥ (режим Tab) отображается на экране устройства и в веб-кабинете, когда для пароля включена отправка логина.

Режим навигации Используйте Tab для одностраничных форм, где поля логина и пароля находятся на одном экране. Используйте Enter для многошаговых процессов входа, где экран логина отделён от экрана пароля — в этом случае увеличьте задержку, если следующая страница загружается медленно.

Wildcard-пароли (случайная генерация на устройстве)

Wildcard-пароль — это особый тип записи, который генерирует криптографически случайный пароль на устройстве каждый раз при вводе через HID клавиатуру. Сгенерированный пароль никогда не появляется в веб-интерфейсе и не сохраняется — он существует только в момент ввода.

СвойствоОписание
Имя записиВсегда отображается как random (управляется системой, изменить нельзя)
Поле пароляПоказывает placeholder [wildcard] — реальный пароль генерируется только во время передачи по HID
ДлинаНастраивается от 4 до 64 символов (Изменить → Длина Wildcard-пароля)
Набор символовБуквенно-цифровые + символы (A-Z, a-z, 0-9, !@#$%^&*()_+-=[]{}|;:,.<>?)
КатегорииНедоступны для wildcard-записей
Авто-отправка / ЛогинНедоступны для wildcard-записей
Кнопка копированияОтключена — wildcard-пароли нельзя скопировать или просмотреть
Бейдж на устройстве🎲 RND бейдж (magenta) на экране
Бейдж в веб-кабинете🎲 Wildcard бейдж в списке

Сценарии использования:

  • Быстрая ротация паролей под давлением — когда нужно немедленно сменить пароль (например, утечка, принудительный сброс, подозрительная активность), но нет времени придумывать надёжный. Устройство генерирует криптографически случайный пароль на лету.
  • Высокобезопасные аккаунты, где нужна максимальная энтропия без раскрытия пароля в каком-либо интерфейсе
  • Сервисы, не поддерживающие менеджеры паролей (например, игровые консоли, Smart TV, ТВ-приставки)
  • Аккаунты, где предпочтительна криптографическая случайность вместо запоминаемости
  • Временные учётные данные, которые часто меняются

Как добавить wildcard-пароль:

  1. В форме добавления пароля отметьте чекбокс Password Wildcard
  2. Установите желаемую длину (по умолчанию: 16)
  3. Нажмите Добавить пароль
  4. Запись появится с именем random и бейджем 🎲
Ограничение одной записи В хранилище может существовать только один wildcard-пароль. Если попытаться создать второй, появится сообщение об ошибке. Удалите существующую wildcard-запись перед созданием новой.
Редактирование Wildcard-паролей Можно изменить только длину (Изменить → Длина Wildcard-пароля). Все остальные поля (имя, значение пароля, категория, авто-отправка, логин) заблокированы. Для «редактирования» других свойств удалите wildcard-запись и создайте вместо неё обычный пароль.
Важно Поскольку wildcard-пароли генерируются заново каждый раз, их нельзя использовать для аккаунтов, где требуется вход через веб-интерфейс или ручной ввод пароля. Они работают только через HID-ввод с устройства. Если потеряете устройство или очистите его, восстановить wildcard-пароль невозможно — сбросьте пароль аккаунта через процедуру восстановления сервиса.

Индикаторы безопасности паролей

При просмотре паролей на экране устройства под маскированным паролем отображается ряд визуальных индикаторов. Значки появляются только при наличии проблем — чистый экран означает отсутствие замечаний.

ЗначокЗначение
🔒🔒🔒 ЗамкиНадёжность пароля: 1 замок (красный) = слабый, 2 замка (жёлтых) = средний, 3 замка (жёлтых) = сильный. Оценка основана на длине и разнообразии символов.
🌐 📱 🖥 🔑Значок категории — отображается над именем пароля. Нажмите для быстрого изменения категории.
DUPДругая запись в хранилище имеет идентичный пароль. Обнаруживается без расшифровки других записей.
PINПароль состоит только из цифр — значительно сниженная энтропия независимо от длины.
NAMEПароль содержит имя записи (или его часть) как подстроку, без учёта регистра.
Миграция Записи, созданные до появления этой функции, мигрируют автоматически при первой загрузке — никаких действий не требуется.

Экспорт и импорт

Работает идентично экспорту ключей — активировать, ввести пароль, скачать файл .enc. Совместимо с decrypt_export.html.

Настройки экрана

НастройкаВарианты
ТемаСветлая, Тёмная
Часовой поясИспользуется для виджета часов на экране устройства
ЗаставкаИзображение при загрузке: SecureGen (оригинал), Blade Runner 2044, Combs
Авто-затемнениеВремя до снижения яркости экрана до 20%. Позволяет экономить заряд, не выключая дисплей полностью. Должно быть меньше тайм-аута экрана. Установите Никогда, чтобы отключить.
Тайм-аут экранаВремя до выключения дисплея и перехода в режим пониженного потребления (CPU замедляется до 40 МГц, контроллер TFT приостанавливается). Нажмите любую кнопку для пробуждения — PIN не требуется. Установите Никогда для постоянного включения экрана.
АвтоблокировкаВремя, после которого устройство переходит в глубокий сон и очищает все чувствительные данные из RAM. При пробуждении требуется PIN. Отсчёт от последней активности — начинается после перехода в псевдосон (если тайм-аут экрана включён) или напрямую от последнего нажатия кнопки (если тайм-аут экрана — Никогда). Должна быть больше тайм-аута экрана при ненулевых значениях обоих параметров. Установите Никогда для отключения. Пробуждение из глубокого сна: нажмите ▼ Низ.
Ориентация экранаОбычная (горизонтально) — по умолчанию, USB-порт справа. Перевёрнутая (180°) — поворот экрана на 180°. Маппинг кнопок меняется автоматически при перевороте. Изменение применяется мгновенно — перезагрузка не требуется. Доступно на обеих платах: T-Display ESP32 и T-Display-S3.
Модуль DS3231 RTCВнешние аппаратные часы. При включении устройство поддерживает точное время без WiFi. Необходим для TOTP в режимах AP и Офлайн. Настройте пины I2C (по умолчанию SDA=21, SCL=22) и нажмите Синхронизировать и сохранить для установки времени по часам браузера.
Экран и блокировка Тайм-аут экрана и автоблокировка настраиваются в одном блоке с единственной кнопкой Сохранить настройки. Оба параметра независимы — каждый можно установить в Никогда. Если автоблокировка меньше или равна тайм-ауту экрана, значение автоматически увеличивается в интерфейсе.

Настройки PIN

PIN устройства (шифрование при запуске)

Управляет PIN-кодом, запрашиваемым при каждой загрузке. Этот PIN шифрует главный ключ устройства — от него зависят все сохранённые данные. Включён по умолчанию, создаётся при первом запуске.

СостояниеЭффект
ВключёнPIN требуется при запуске. Главный ключ зашифрован на диске.
ОтключёнPIN не требуется при запуске. Главный ключ хранится незашифрованным — при краже устройства данные можно извлечь.
Важно После отключения главный ключ нельзя перешифровать без сброса до заводских настроек. Сброс требует повторного импорта всех ключей и паролей из резервных копий.

Аппаратный PIN подтверждения BLE

Дополнительный PIN, запрашиваемый на самом устройстве перед любой BLE-передачей пароля. Предотвращает несанкционированные передачи при доступе посторонних к устройству.

Пин-код уничтожения (Duress PIN)

Отдельный экстренный PIN-код, который при вводе во время загрузки запускает немедленное и скрытное уничтожение всех данных устройства.

ПараметрОписание
ДлинаСовпадает с длиной основного PIN (4–10 цифр). Настраивается автоматически.
ЗначениеДолжен отличаться от основного PIN.
ПоведениеУстройство показывает PIN OK — неотличимо от нормальной разблокировки — затем скрытно стирает все данные и перезагружается.
ХранениеХранится как отдельный хеш PBKDF2-HMAC-SHA256. В открытом виде не сохраняется.
Поддержка платОбе платы: T-Display ESP32 и T-Display-S3.
Обязательное условиеСтартовый PIN должен быть включён. Пин-код уничтожения может сработать только на экране разблокировки стартовым PIN. Если стартовый PIN отключён, раздел пин-кода уничтожения становится серым и недоступным, а ранее настроенный пин-код уничтожения автоматически удаляется.

Что уничтожается

При вводе Duress PIN до перезагрузки необратимо удаляется:

  • Все TOTP / HOTP ключи
  • Все пароли
  • Главный ключ устройства (/device.key)
  • Учётные данные WiFi
  • Данные BLE-сопряжения (раздел NVS)
  • Все сессии, учётные данные веб-кабинета, конфигурация PIN
  • Хеш самого Duress PIN
  • Весь раздел файловой системы (~3.9 МБ) — стирается на аппаратном уровне через esp_partition_erase_range, что делает восстановление данных невозможным даже при прямом доступе к чипам флеш-памяти

Как включить

В веб-кабинете откройте вкладку Pin и прокрутите до раздела Duress PIN. Включите переключатель, введите и подтвердите PIN, затем нажмите Сохранить Duress PIN. Для отключения — выключите переключатель: хеш-файл удаляется с устройства.

⚠ Предупреждение — необратимо
Запроса подтверждения нет. Ввод Duress PIN немедленно и безвозвратно уничтожает все данные. Используйте только в ситуациях, когда устройство может быть скомпрометировано и необходимо предотвратить извлечение данных.

Скрытое пространство

Скрытое пространство — второе независимое зашифрованное хранилище. При загрузке ввод альтернативного PIN-кода открывает полностью изолированный набор ключей, паролей и отдельный аккаунт веб-кабинета. Снаружи устройство ведёт себя одинаково независимо от того, какое пространство активно.

Принцип работы

Файл ключа устройства содержит два независимых зашифрованных слота. Каждый слот защищён собственным PIN-кодом и солью. Слот, который успешно расшифровывается, определяет загружаемое пространство — второй слот в течение сессии не читается.

Скрытое пространство требует активного стартового PIN-кода. Отключить стартовый PIN, пока существует скрытое пространство, нельзя — сначала нужно удалить скрытое пространство (потребуется ввести PIN от Space B на устройстве), и только затем отключать стартовый PIN.

Шаг 1 — Включение скрытого пространства

Откройте веб-кабинет из пространства A → Настройки → Скрытое пространство → включите переключатель → подтвердите. Устройство перезагружается.

Шаг 2 — Установка PIN пространства B

При следующей загрузке сначала запрашивается основной PIN (разблокировка пространства A), затем новый PIN для пространства B. Коды должны отличаться. После настройки устройство снова перезагружается и загружается в пространство A в обычном режиме.

Вход в пространство B

На экране ввода PIN введите PIN пространства B вместо PIN пространства A. Устройство загрузит скрытое хранилище — изолированные TOTP-ключи, пароли и отдельный аккаунт веб-кабинета.

Общий доступ к WiFi

По умолчанию пространство B не имеет WiFi-данных. В Настройки → Скрытое пространство (контекст пространства A) включите Передать WiFi скрытому пространству, чтобы пространство B использовало WiFi пространства A при первом запуске. Данные перешифровываются с помощью ключа, производного от чипа — ни одно пространство не может прочитать ключ устройства другого.

Отключение скрытого пространства

Из пространства B: Настройки → Скрытое пространство → отключите переключатель → подтвердите. Слот B будет обнулён, все файлы пространства B удалены. Данные пространства A не затрагиваются.

Удаление необратимо. Все ключи, пароли и данные пространства B уничтожаются без возможности восстановления.

Сброс настроек и скрытое пространство

Сброс до заводских настроек доступен только из пространства A. Полный сброс уничтожает оба пространства путём форматирования файловой системы. Инициирование сброса из пространства B заблокировано.

Первый вход в пространство B

Пространство B начинается пустым — без ключей, паролей и аккаунта веб-кабинета. Зарегистрируйте новый аккаунт при первом входе в веб-кабинет. Если общий WiFi не включён — настройте WiFi-данные в веб-кабинете.

Настройки

Смена пароля веб-кабинета

Требования: минимум 8 символов, заглавная буква, строчная буква, цифра, специальный символ (!@#$%).

Смена пароля AP

Пароль собственной WiFi точки доступа устройства.

Сеть WiFi

Измените учётные данные WiFi-сети, к которой устройство подключается в режиме WiFi Client. Введите SSID сети (используйте кнопку Сканировать для поиска доступных сетей), пароль и подтверждение пароля, затем нажмите Сохранить данные WiFi.

Примечание Изменения вступают в силу после перезагрузки. Текущее соединение не прерывается.

Bluetooth

Имя BLE-устройства — максимум 15 символов. Это имя отображается при сопряжении.

mDNS

Имя хоста для доступа в локальной сети. После сохранения устройство доступно по адресу http://<hostname>.local.

Режим запуска

Экран по умолчанию при загрузке: просмотр TOTP/HOTP или менеджер паролей.

Режим HID

Только T-Display-S3. Режим вывода по умолчанию при передаче паролей через эмуляцию аппаратной клавиатуры: BLE HID или USB HID. Это предвыбранный вариант в HID-промпте — другой режим остаётся доступен для выбора до начала передачи. Заводское значение: BLE HID.

Режим загрузки

Сетевой режим по умолчанию при загрузке: WiFi Client, Режим AP или Офлайн. Выбранный режим становится дефолтным при тайм-ауте на экране выбора — два других режима остаются доступны через кнопки. Изменения вступают в силу при следующей перезагрузке. Заводской режим: WiFi Client.

Автовыключение веб-сервера

Автоматически останавливает веб-сервер после бездействия: 5 мин, 10 мин, 1 час или никогда.

ВариантПоведение

Примечание — для персистентных сессий требуется синхронизация времени
Режимы с таймером (1 час – 3 дня) требуют синхронизированного системного времени для проверки возраста сессии после перезагрузок. В режиме WiFi время синхронизируется автоматически через NTP. В режимах AP и Офлайн — вручную через модуль DS3231 RTC (Настройки дисплея → DS3231 RTC → Синхронизировать и сохранить).
В режиме AP без RTC таймерные режимы автоматически переходят в режим до перезагрузки — сессия действует только до ребута с учётом 15-минутного таймаута неактивности.
